# Withings 驱动调试指南（试验性）

[English](withings-debug.md)

Withings 驱动是**试验性**的。它根据公开的协议资料编写，尚未在真机上验证。驱动**只读**：只读取体重秤上存储的测量记录，不会删除记录、不会修改体重秤的 Wi-Fi 或账号设置，也不会升级固件。ScalePaw 与 Withings 公司无关。

如果你有 Withings 体重秤并愿意帮忙测试，本指南说明要测试什么、需要反馈哪些信息。

## 1. 支持的型号

| 型号 | 广播名称 | 状态 |
| --- | --- | --- |
| Body Smart（WBS13） | `Body Smart…` | 主要目标；参考实现在此型号上测试过 |
| Body+（WBS05） | `Body+…` | 应该可用；配对不需要配对码 |
| Body Comp、Body Scan、Body Cardio | `Body Comp…`、`Body Scan…`、`Body Cardio…` | 未知；仅按名称识别 |

驱动也会认领广播 Withings 服务 UUID（`00000020-5749-5448-…`）的任何设备。在蓝牙列表中显示为“Withings …（试验性）”。

## 2. 准备工作

1. **先在 Withings App 中完成体重秤设置。** 体重秤必须绑定到一个 Withings 账号。ScalePaw 无法完成首次设置。
2. **获取账号密钥（kl）。** 每台体重秤有一个只有账号知道的 32 位密钥。没有它，体重秤会拒绝通信。
   - 在 ScalePaw 中：设置 → 蓝牙 → 选中体重秤 →“从 Withings 获取密钥”并登录。匹配的体重秤的密钥会自动保存。
   - 仅支持**邮箱加密码**登录的账号。使用 Apple 或 Google 登录、或开启了两步验证的账号会提示“Withings 没有建立会话”。这种情况下请用其他方式获取密钥（例如 [withings-local](https://github.com/pierosavi/withings-local)），并粘贴到“账号密钥（kl）”输入框。
   - 邮箱和密码只会发送给 Withings，不会被保存。ScalePaw 读取密钥后立即退出登录。
3. **保持“同步体重秤时钟”开启**，除非你在专门测试它。它会在每次连接时设置体重秤的时间和时区。

## 3. 搜索与配对

- 体重秤只在**称重后约一分钟内**，或**按住按钮 3 秒**（设置模式）后才会广播。先在 ScalePaw 中开始搜索，再站上体重秤。ScalePaw 最多等待两分钟。
- **Body Smart** 会在屏幕上显示 6 位配对码，请在 Android 配对对话框中输入。**Body+** 无需配对码。
- 如果与 ScalePaw 配对后体重秤显示“Setup failed”之类的提示，这是正常的：ScalePaw 不执行 Withings 的设置流程。体重秤仍可继续配合 Withings App 使用。
- 如果 ScalePaw 提示“体重秤处于设置模式”，说明体重秤还没有绑定 Withings 账号，请先在 Withings App 中完成设置。

## 4. 测试项目

请逐一尝试以下组合，并记录结果（能否连接？记录是否导入？有什么错误提示？）：

| 体重秤模式 | Withings App 蓝牙 | 预期 |
| --- | --- | --- |
| 纯蓝牙 | 手机蓝牙开启，Withings App 已关闭 | 应该可用；主要场景 |
| 纯蓝牙 | Withings App 已打开 | Withings App 可能抢先连接 |
| Wi-Fi | Withings App 已关闭 | 未知：Wi-Fi 体重秤上传后可能停止广播 |
| Wi-Fi | Withings App 已打开 | 未知 |

以下信息也很有用：

- 连续称重两三次，然后连接一次。是否所有记录都导入了，时间是否正确？
- 称重、连接，然后不称重再连接一次。ScalePaw 应提示“没有新记录”。
- 关闭“同步体重秤时钟”，称重并连接。时间戳是否仍然正确？
- 出现了哪些数值：体重、体脂、肌肉、水分、骨量、内脏脂肪、基础代谢、代谢年龄、心率？

## 5. 收集诊断信息

### App 内诊断（推荐）

会话失败时，驱动会保留一份简短的日志。打开设置 → 蓝牙 → 选中体重秤，滚动到“上次会话”，点击**复制诊断信息**，然后粘贴到 issue 或消息里。

日志包含消息类型和长度、固件版本和错误码。**不包含**账号密钥、MAC 地址、挑战字节或任何测量数值。

### adb logcat

使用 debug 版本并开启 USB 调试：

```sh
adb logcat | grep "ScalePaw/"
```

标签为 `ScalePaw/WithingsHandler` 的是驱动日志；`ScalePaw/GattLink` 显示蓝牙层面的失败，例如配对错误。

### nRF Connect

如果 ScalePaw 完全找不到或连不上体重秤，可以借助 [nRF Connect](https://play.google.com/store/apps/details?id=no.nordicsemi.android.mcp)：

1. 称重后立即扫描，找到体重秤。
2. 截图广播内容：名称、服务 UUID 和厂商数据。
3. 连接后截图服务列表。

分享截图前请**打码或删除 MAC 地址**。

## 6. 常见问题

| 提示或现象 | 可能原因 | 处理办法 |
| --- | --- | --- |
| 找不到体重秤 | 体重秤没有在广播 | 开始搜索后立即站上体重秤，或按住按钮 3 秒 |
| 配对失败或反复要求配对 | 配对码错误，或存在旧的配对记录 | 在 Android 蓝牙设置中删除体重秤后重试 |
| “需要账号密钥” | 未保存密钥 | 登录 Withings 或粘贴密钥 |
| “拒绝了账号密钥”（错误 -6） | 密钥错误或已过期 | 重新登录；体重秤重新设置后密钥会改变 |
| “认证完成前，体重秤拒绝了请求”（错误 -5） | 认证未完成 | 复制诊断信息并反馈 |
| “无法证明它知道账号密钥” | 密钥属于另一台体重秤 | 检查登录页面中选择的是哪台体重秤 |
| 记录日期为 1970 年或被跳过 | 体重秤时钟未设置 | 保持“同步体重秤时钟”开启 |
| “停止响应” | 连接中断 | 让手机靠近体重秤后重试 |
| “对命令 Y 返回错误 X” | 未知的体重秤行为 | 复制诊断信息并反馈 |

## 7. 隐私

- 账号密钥只保存在手机上 ScalePaw 的驱动设置中。
- 邮箱和密码只会通过 HTTPS 发送到 `scalews.withings.net`，并且只在登录期间保存在内存中。
- 诊断信息已按上述方式脱敏。分享前仍请自行检查一遍。

## 8. ScalePaw 从不发送的命令

为了保证体重秤和账号的完整，驱动从不发送：

- 存储记录 action 2（从体重秤删除记录）
- `ASSOCIATION_KEYS_SET`（308）和 `SETUP_OK`（275），它们会改变账号绑定
- `SCALE_SESSION`（269）
- 任何 Wi-Fi 配置命令
- 任何固件升级命令

驱动只发送：`PROBE`、`PROBE_CHALLENGE`、`TIME_SET`（开启时）、`CONNECT_REASON`、`STORED_MEASURE`（action 0 和 1，只读）、`SYNC_OK` 和 `DISCONNECT`。
